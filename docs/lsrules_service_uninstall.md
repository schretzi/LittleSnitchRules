## lsrules service uninstall

Unload the LaunchAgent and remove its plist

### Synopsis

Unload the job and delete its plist. Logs in ~/Library/Logs are left in place.

```
lsrules service uninstall [flags]
```

### Options

```
  -h, --help   help for uninstall
```
